# Портфолио в стиле notes.andymatuschak.org: дизайн

## Цель
Переделать сайт-визитку в стек заметок: клик по внутренней ссылке открывает заметку справа, предыдущие панели сжимаются в вертикальные полоски. Контент только из текущего сайта, новых текстов нет. Статический сайт для GitHub Pages, без сборки.

## Заметки (`notes/<slug>.html`, фрагменты контента)
| slug | содержимое |
|---|---|
| kirill-bogatov | главная: описание, портрет, ссылки на разделы |
| pet-projects | вводная и список навыков |
| wumpus, drawing-ideas, princess-dragon-knight, dragons-and-lotos, idea-generator | описание навыка, картинка, внешние ссылки |
| articles | 4 статьи (Хабр, Cossa), группы «Методология» и «Пользовательский опыт» |
| contacts | Telegram, почта |

Каждый файл содержит `<h1>` и тело заметки. Внутренние ссылки: `<a href="/notes/<slug>.html" data-note="<slug>">`.

## Поведение стека
- Панели шириной ~625px идут горизонтально, нужная прокручивается в поле зрения.
- Предыдущие панели сжимаются до полосок ~40px с вертикальным заголовком. Клик по полоске возвращает к заметке и закрывает всё правее.
- Клик по ссылке в панели N заменяет всё правее N и открывает новую заметку. Если заметка уже в стеке, происходит прокрутка к ней.
- URL: `/?stackedNotes=a&stackedNotes=b` (первая заметка в пути/параметре `note`, остальные в `stackedNotes`). Работают «назад»/«вперёд» (`history.pushState`/`popstate`) и прямые ссылки на глубокий стек.
- Внизу заметки блок «Ссылаются на эту заметку»: JS загружает все заметки один раз и строит обратные ссылки.
- Мобильные (<700px): панели полноэкранные, сверху ссылка «назад» вместо полосок.
- Без JS каждая заметка открывается как обычная страница (прогрессивное улучшение).

## Визуал
Тёплый серо-бежевый фон, белые панели с тонкой тенью, шрифт с засечками (системный стек), акцентный цвет у внутренних ссылок, внешние помечены ↗. Тёмная тема через `prefers-color-scheme`.

## Файлы
- `index.html` — оболочка со стеком.
- `notes/*.html` — заметки.
- `styles.css`, `script.js` — переписываются.
- `skills/index.html` — заменяется редиректом на `/?note=pet-projects`.
- `start.bat` — локальный сервер (уже есть).

## Проверка
Локально через `start.bat`: открытие и схлопывание панелей, возврат по полоске, «назад», глубокая ссылка, бэклинки, мобильная ширина, тёмная тема.
